# 下载说明 / How to download

## 中文名文件显示为 Unknown file？

本仓库的原始文件名含中文，平台的 Diff / 文件面板无法解析，会显示 `Unknown file`。
**本 `download/` 目录里的所有文件都改成了英文名**，可以直接查看与下载。

| 想下载什么 | 用这个文件 |
| --- | --- |
| 两份 PPT（直接点，各约 110 KB） | `PPT-01-...pptx` / `PPT-02-...pptx` |
| 两张 18 页预览图（不用装 Office 就能通读） | `PREVIEW-PPT-01-18pages.png` / `PREVIEW-PPT-02-18pages.png` |
| 全部材料（PPT + 7 份文档 + 6 份模板 + 3 份规格 + 2 份评分报告） | `ALL-MATERIALS.zip`（0.3 MB） |

## 下载按钮在哪

文件在**查看器面板**里打开后，下载按钮在**该面板的右上角**。

你之前截图看到的是 **Diff（对比）面板** —— 那是查看代码改动的面板，不是下载面板。
要看文件本身：关掉 Diff（点右上的 ×），或在左侧文件列表里点文件名。
