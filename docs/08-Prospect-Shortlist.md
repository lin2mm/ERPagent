## 一、一个关键校准：规模按**员工数**看，不要按营收

材料加工与工程类企业的营收被原材料和工程款放大得很厉害。一家 160 人、年产值 20 亿的彩涂板厂，
在组织复杂度上远低于一家 160 人、年产值 1 亿的精密制造厂。

> **判断口径**：员工 **80–800 人**、且**没有独立 IT 部门** → 命中甜点区。
> 营收只用来判断"买得起"，不用来判断"推得动"。

## 三、S 级与 A 级详解（成功面 / 失败面 / 切入点）

### S1 · 山东省博兴县聚鑫源精密薄板有限公司 —— 29/35

| | |
| --- | --- |
| 城市 | 山东省滨州市博兴县店子镇 |
| 网址 | `jxyjmbb.com`（另有集团品牌站，见官网导航） |
| 主营 | 镀锌板、镀铝锌板、彩涂钢板、印花彩涂；旗下三个彩钢品牌 |
| 规模 | 集团多基地、多生产线；公开资料称**出口占比 60%+，彩涂板（卷）出口量连续多年全国第一** |

**成功面（为什么它值得优先谈）**

- **外部压力接近满分（E3）**：出口 60% 以上、销往 70 多个国家 —— 海外客户对**批次追溯、质量档案、认证**的要求是硬的，不是你劝他做，是他客户逼他做。
- **痛点具体（E2）**：多品牌（高端线"鲁匠"与常规线并存）+ 多规格 + 多等级，**等级与批次一旦错发，损失直接可算**。
- **卷材为主（E7 满分）**：这正是案例 A 的原型场景 —— 呆滞分档、等级匹配发货、超产上限、卷料倒冲。
- 2017 年做过高洁净彩涂产线的升级改造，**说明这家企业有为"品质与管理"付钱的先例**。

**失败面（要核实什么）**

- 出口型企业的管理注意力通常在外贸与订单，**内控投入意愿需当面确认**：问他"客户验厂时最怕被查什么"。
- 集团下多主体，**权限隔离与多组织**会成为第一个技术议题 —— 这是我们案例 B 的强项，但要确认他是否愿意先做一条线。
- 出口企业往往已有外贸 ERP，**要确认现有系统边界**，别踩到"重复录单"的雷。

**建议切入点**：客户验厂 / 出口批次追溯 → 一卷料的完整档案（成品→卷→批号→基板供应商）。

### S2 · 广州市仪美医用家具科技股份有限公司（新三板 839643）—— 29/35

| | |
| --- | --- |
| 城市 | 广东省广州市白云区 |
| 网址 | 官网需检索（新三板公开转让说明书中有披露）；备用检索：`cninfo` / 全国股转系统 |
| 主营 | 医用家具研发、生产、销售 + **工程安装**；医疗空间整体解决方案 |
| 规模 | 新三板挂牌，注册资金约 2.35 亿、员工约 100–300 人，工程案例 600+ 家 |

**成功面**

- **新三板挂牌 = 治理与数据规范压力**：有报表要求、有合规要求，对"数据说得清"有天然需求。
- **工程安装型业务（E2/E3 高）**：医院项目是招投标 + 分批供货 + 现场安装，**交期、齐套、变更留痕**全都是硬约束。
- 医疗家具是**强监管场景**：材料、检测报告、批次可追溯是行业常态，客户的"追溯"语言不需要我们教。
- 600+ 工程案例 = **订单种类极多、非标程度高**，正是案例 B"两段拆单 + 齐套校验"的用武之地。

**失败面**

- 新三板公司**决策链可能比家族企业长**，要确认究竟谁能拍板（B1 核实项）。
- 医疗家具行业毛利被集采与招标压得很紧，**预算可能敏感** → 第一次见面必须带"算得清的账"，别谈概念。
- 若已上线某类 ERP，要确认**是否留有接口与扩展位**。

**建议切入点**：一个医院项目的"从下单到安装齐套"全流程台账 + 一樘/一柜的三分钟档案。

### S3 · 上海雅轩办公家具有限公司 —— 28/35

| | |
| --- | --- |
| 城市 | 上海市嘉定区 |
| 网址 | 需检索（公开报道中有公司信息）；两大生产基地：江苏海安、浙江宁波 |
| 主营 | 系统家具、医疗家具、教育家具、空间智能化整体方案 |
| 规模 | 注册资本 1.08 亿元、员工约 160 人、**年产值 3 亿元 +**、两大生产基地 5 万㎡+、六个品牌矩阵 |

**成功面**

- **规模正中甜点区**：160 人 / 3 亿产值 —— 复杂到需要系统，小到老板还能亲自拍板。
- **双基地 + 多品牌**：天然的**组织隔离与权限**需求（A 基地看不到 B 基地），正是我们产品化程度最高的能力。
- 医疗 + 教育 + 办公三条业务线并行，**订单结构与毛利口径差异大** → 老板最需要"哪个业务线到底赚不赚钱"。
- 上海企业对新事物接受度高（B3 数字化体感通常不差）。

**失败面**

- 多基地企业对"上线期间影响交付"极度敏感 → **必须用"只读驾驶舱 + 两周可见"打开**，不要一上来谈全厂上线。
- 六品牌矩阵意味着可能存在多套小系统，**要盘清现状再报价**。
- 上海市区招人成本高、IT 人员流动大，**实施期客户的对接人可能中途更换** → 合同里要写"关键用户不换人"。

**建议切入点**：老板手机上的三个数字（在手订单与交期 / 各业务线毛利 / 异常待办）。

### S4 · 阜城县华营集成房屋有限公司 —— 27/35

| | |
| --- | --- |
| 城市 | 河北省衡水市阜城县（当地有 48 家集成房屋上下游企业） |
| 网址 | 需检索（河北日报等媒体报道） |
| 主营 | 拓展式集装箱别墅（**产品全部出口**，主打欧美市场） |
| 规模 | 20 余人外贸团队、月销 200+ 套、公开报道称营收突破千万元（口径需核实） |

**成功面**

- **全出口 = 外部压力满分**：欧美客户对产品标准、验厂、批次记录的要求是准入门槛。
- 折叠/拓展结构 = **强非标 + 强齐套**：一个模块的缺件会导致到岸后无法安装，代价极高（正是我们"缺件拦在厂里"的价值）。
- 阜城形成产业集群（48 家上下游）→ **一家做成了，旁边 47 家都是转介绍线索**。这是本名单里**复制价值最高的一家**。
- 从活动板房转型出海，说明**老板有"必须变"的危机感**（B4/B5 通常不差）。

**失败面**

- 公开报道口径不一（营收"千万元"量级偏低），**规模与现金实力要现场核实**；太小则不适合本方案。
- 出口业务由外贸团队驱动，**老板可能更关注获客而非内控** → 见面要先讲"到岸后装不起来"的损失。
- 北方县域企业，**数字化体感（B3）** 需要现场判断。

**建议切入点**：一个集装箱模块的"出厂齐套清单 + 到岸安装不返工"。

## 五、线索来源：自己持续爬，比名单更重要

### 1. 招标公告（最高效的客户名单来源）

**政府采购网、各省公共资源交易平台**上，**中标公告里的企业名就是精准客户名单** ——
有人下单、有预算、有资质要求、有交期约束，四条全中。

- 中国政府采购网 `ccgp.gov.cn` — 搜"医用家具""实验室家具""防火门""门窗工程"
- 各省公共资源交易中心 — 搜"家具采购""门采购""安装工程"
- 招标搜索站（如 `zhaobiao.cn`）— 按地区 + 品类订阅

**顺带一招**：招标文件里的"分批交货、现场安装、工期延误违约金"条款，
就是他最痛的条款 —— **把这条款原文抄进你的方案第一页**，说服力比任何 PPT 都强。

## 六、拿到名单后怎么用（三步）

1. **先做 10 分钟桌面核实**：把名单里企业的官网、员工数、现有系统、是否有外贸/招投标，
   填进 `templates/07-Customer-Qualification-Checklist.md`，把"预估分"换成"核实分"。
2. **再打三个探路电话**（不必见面）：
   - "你们最近有没有客户要求提供批次追溯或验厂资料？"
   - "现在订单的交期，车间能看到进度吗？"
   - "今年有没有在信息化上有预算/招人？"
   三个都答不上来 → 直接降到 C 级，不要浪费一次出差。
3. **值得投入的，走五步阶梯**（`docs/07` 第五节）：走车间 → 一页症断书 → 只读驾驶舱 → 试点 → 推广。
