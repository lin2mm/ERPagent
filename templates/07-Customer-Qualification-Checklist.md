## 第 0 步 · 一票否决（任一不过 → 直接放弃或搁置）

- [ ] **能见到拍板的人**：股权清晰、创始人或家族实际控制；不是只跟 IT、生产部长谈。
- [ ] **近 12 个月没有失败的信息化项目**；若有，老板能说清原因，且愿意听我们怎么回应。
- [ ] **业务负责人若反对，老板明确表示会处理**（生产 / 设计 / 财务）。
- [ ] **有数据载体**：在用进销存 / ERP / 总账之一，且有物料编码（编码乱没关系）。
- [ ] **有现金**：预算几十万至几百万且不影响正常经营 —— 不靠贷款、不靠赊账做项目。
- [ ] **一把手愿意亲自下场**：能参加双周演示、能安排关键用户工时。**（最强的筛选器）**

> 结论：☐ 全部通过，进入打分 ☐ 未通过（第 ____ 条）→ 搁置，不投入售前资源

## 第 3 步 · 负面清单（命中任一条扣 5 分；带 ★ 的直接放弃）

- [ ] 老板不在现场，全权交给职业经理人 ★
- [ ] 只问"多少钱"，不问"怎么做" ★（你只是他的比价工具）
- [ ] 要"先做个小样看看"，却不肯投入任何资源
- [ ] 老板认为自己什么都懂，要你"按我说的做"
- [ ] 业务负责人明确反对，而老板不打算处理 ★
- [ ] 数据极度混乱，且没人愿意清洗 ★
- [ ] 家族内斗 / 股权纠纷，决策随时被推翻 ★
- [ ] 行业正在衰退，或企业准备卖掉
- [ ] 近 12 个月刚有失败的信息化项目，且说不清原因
- [ ] 要你先做完整方案再谈钱（大概率拿去给别家报价）★

**命中 ★ 共 ____ 条　其余命中 ____ 条**

## 第 4 步 · 定级与打法（总分 = 企业侧 + 老板侧，满分 70）

| 级别 | 分数 | 打法 | 投入 |
| --- | --- | --- | --- |
| **S 级** | ≥ 56 | 立即投入：安排同行业活案例参观 → 4 周内做出"只读驾驶舱" → 直接谈分期与里程碑 | 全力 |
| **A 级** | 42–55 | 重点培育：先做半天走车间 + 1 页症断书，建立信任后再谈主线 | 中等 |
| **B 级** | 28–41 | 保持观察：定期发行业案例、邀请参加活动，等外部压力出现 | 低 |
| **C 级** | < 28 | 礼貌退出；命中一票否决或 ★ 的，同样按 C 级处理 | 零 |

**两条修正规则**

1. 总分高但**老板不愿亲自下场** → 按 B 级处理。
2. 总分中等但**老板肯下场、且有外部压力** → 可按 A 级投入。

## 第 5 步 · 见面必问的 12 个问题（用来填上面的分）

**关于钱**

- [ ] 去年哪三笔钱最让您心疼？大概各是多少？
- [ ] 单张订单赚不赚钱，您什么时候能知道？
- [ ] 这次投入大概什么量级，走什么审批流程？

**关于人**

- [ ] 这事谁能拍板？除了您，还有谁的意见很关键？
- [ ] 生产、设计、财务的负责人，您觉得他们会怎么想？
- [ ] 上次搞系统是谁在推？最后为什么停了？

**关于事**

- [ ] 从接单到发货，最常卡在哪一步？一般卡多久？
- [ ] 客户投诉最多的是哪一类？
- [ ] 现在有没有客户要求溯源，或要求提供台账？

**关于风险**

- [ ] 如果三个月看不到东西，您能接受吗？
- [ ] 上线期间，您最怕影响到什么？
- [ ] 数据这块，您自己觉得乱到什么程度？

## 第 6 步 · 走车间 30 分钟：看这 8 个信号

- [ ] 排产用的是白板或纸质单 → 管理全靠人，系统有空间
- [ ] 货架上有积灰的原料 / 卷料 → 呆滞资金，账就在眼前
- [ ] 工人说不出手上这批货给哪个客户 → 追溯意识弱，也是机会
- [ ] 班组长用本子记数 → 计件争议的源头
- [ ] 有闲置的大屏或扫码枪 → 上次失败的遗迹，同时是现成资产
- [ ] 打标 / 喷码设备在跑，但数据没进系统 → **最值钱的切入点**
- [ ] 问"上个月报废多少" → 答不上来，说明账不清楚
- [ ] 墙上还有某个系统的旧海报 → 上次用了多久？现在谁在用？

## 附：这张表为什么这样设计

| 设计 | 原因 |
| --- | --- |
| 一票否决放在最前 | 这六条任一不过，后面打分再高也没用；先淘汰，再评估 |
| 老板侧与**企业侧同权**（各 35 分） | 企业好但老板不动，项目必败；企业一般但老板肯下场，常常做得成 |
| B1 亲自下场意愿 ★ | 经验上这是**最强的单一预测因子** |
| 负面清单给"扣分"而不是"否决" | 除 ★ 外，多数缺点是可以用报价、范围、节奏来对冲的 |
| 两条修正规则 | 避免"打分高就投、打分低就放"的机械执行 |
| 走车间 8 个信号 | 老板说的和车间真实情况常常不一致，这一页用来交叉验证 |
| 首页就有"结论记录" | 逼自己在离开前给出定级和下一步，避免"回头再说" |
