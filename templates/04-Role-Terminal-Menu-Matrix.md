## 四、数据范围隔离

| 层级 | 规则 | 是否启用 |
| --- | --- | --- |
| 组织隔离 | A 部门/厂区看不到 B 部门/厂区的数据 | ☐ |
| 集团穿透 | 集团管理层可穿透看全部，但**要单独授权且全程留痕** | ☐ |
| 外部单位隔离 | 外部单位只能看到发给它的那部分单据 | ☐ |
| 字段级隐藏 | 敏感字段（成本、毛利、单价）按角色隐藏 | ☐ |
| 导出控制 | 导出需授权，且记录审计 | ☐ |
| 下载控制 | 图纸等核心资产**默认关闭下载**，按人按厂授权 | ☐ |

## 五、设计规范自检

```
☐ 终端按"场景"切，不按"角色"切（同一角色可能用多个终端）
☐ 菜单可见性有四种：可操作 / 只读 / 不可见 / 限定说明
☐ 菜单顺序 = 生意顺序（销售→订单→设计→技术→计划→采购→生产→质量→仓储→交付→财务）
☐ 每个角色的登录落点 = 该岗位的工作现场（不是首页）
☐ 工作台自动装配成该角色的样子：我的待办 + 异常计数 + 快捷入口
☐ 菜单按角色收窄（"界面越窄，操作越专注"）
☐ 人员转岗/离职的管理流程已定（转岗改角色；离职停用但保留历史审计）
☐ 虚线角色（新设岗位）已确认其能力要求与培训路径
```
