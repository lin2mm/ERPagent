| 3 | | | | | | | |
| 4 | | | | | | | |
| 5 | | | | | | | |

**类型说明**

```
物理不可能 …… 客观做不到（产能上限、物料未到厂）→ 争议最低，优先做
合规/认证 …… 外部规则强制（认证校验、等级匹配）  → 争议低
质量/工艺 …… 做得到但会出不良（首件未确认、换料不匹配）→ 争议中
管理规则 …… 内控要求（信用额度、月份管控）      → 争议最高，需老板背书
```

**五条设计规范自检**

```
☐ ① 拦截必须给出原因和出路（不是死墙）
☐ ② 闸门能"走流程绕过"（审批 + 留档），不是绝对禁止
☐ ③ 拦截有视觉/听觉反馈（红屏 + 告警声）
☐ ④ 物理不可能类与合规类优先上线；管理规则类需老板签字后上
☐ ⑤ 每道闸门都问过："有没有人会因此没法干活？" 如果有，先给出路
```

**签字**：业务负责人 ____________ 总经理 ____________ 日期 ________

**边界表 B · 与人的边界**

| 事项 | 系统只做 | 由人做 |
| --- | --- | --- |
| 工资/奖金 | 出计件汇总、勾稽、稽核 | 定薪、发放 |
| 质量放行 | 汇总证据、比对规则 | 批准特采/让步 |
| 客户沟通 | 生成要点、生成草稿 | 对外发出 |
| 处罚/考核 | 提供数据 | 决定 |

**自检**：凡是会引起强对抗的决策（发多少钱、罚不罚），**系统只提供依据，不做决定**。
