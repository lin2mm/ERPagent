# ERPagent · 制造企业数字化与 Agent 化交付知识库

本仓库是一套**可复用的交付方法 + 模板 + 机器可读规格 + 可直接讲的 PPT**，
来自两份真实交付物的深度拆解：

| 材料 | 性质 | 提取出的价值 |
| --- | --- | --- |
| 一份制造执行系统操作手册（132 页 / 5 端 / 19 模块 / 4 附录） | **建成之后**的产品说明书 | 产品结构、状态机、闸门、算法与工程机制 |
| 一份智能制造一体化方案（含 5 张架构图） | **建成之前**的销售与架构方案 | 价值叙事、总体架构、权限模型、交付节奏与商务对价 |

两份材料中的企业名、品牌名、人名、客户与供应商名已全部剔除，
只保留**可迁移的结构、机制、规则、数字与交付方法**。
分别称为 **案例 A**（卷材辊涂/裁片工厂）与 **案例 B**（非标定制门工厂）。

## 两份售前说服版（老板决策简报，各 16 页）★ 用来提高成交率

上面两份是**机制版**（讲"系统长什么样"）；下面两份是**说服版**（讲"老板为什么要买"）。
同一套 16 页骨架分别套用两个案例 —— 换一个客户，只要填一份内容就能再出一份。

| 文件 | 内容 |
| --- | --- |
| `pdf/PITCH-01-Roll-Material-MES-Boss-Briefing.pdf` | 案例 A 老板版：卷料上最贵的四样东西 → 八样好处 → 算一笔账 → 四顾虑直答 → 谁会反对 → 不做什么 → 要您出什么 → 钱怎么算 → 五步节奏 → 负面测试验收 → 适配边界 → 推行机制 → 下一步 → 一页速查 |
| `pdf/PITCH-02-Custom-Door-Boss-Briefing.pdf` | 案例 B 老板版：同骨架，换成非标定制的账（交期 40→25 天、计件当天进账、订单毛利当天见、齐套校验） |

设计依据见 `docs/07-Boss-Perspective-Sales-Strategy.md`，核心是四条：

1. **老板买的不是系统，是"少赔钱 / 多接单 / 不用天天盯"** —— 所以开场是账单，不是功能清单；
2. **最大的顾虑不是价格，是"我推不动"** —— 所以有专页讲推行机制（先让一线受益、驾驶舱零操作、只跑三道工序）；
3. **主动减承诺是最强的信任动作** —— 所以有不做什么、适配边界、口径声明各一页；
4. **把第一次投入和第一次风险做小** —— 所以有"半天走车间 → 1 周症断书 → 2 周只读驾驶舱 → 试点 → 推广"的五步阶梯，每步都能停。

PDF 与可编辑 PPTX 同时提供（`ppt/PITCH-0x-*.pptx`），逐页 PNG 在 `download/PITCH-0x-slides-png/`。

**另出 8 页「20 分钟面谈版」**（`pdf/PITCH-01-Short-Roll-Material-MES.pdf`、`pdf/PITCH-02-Short-Custom-Door.pdf`）：
只留 16 页版的第 02/03/04/05/11/13/15/16 页 —— 账单 → 三件事 → 八样好处 → 算账 → 节奏 → 适配 → 下一步 → 速查，
不带封面，翻开第一页就进正题。职责分工：**16 页版留底（会后发给客户），8 页版现场讲（20 分钟一套走完）**。
两个版本内容完全一致，不会出现说法不一。

## 核心结论（六条）

1. **两个案例的核心不是软件功能，而是一条主线 + 一道闸门。**
   案例 A 的主线是**卷号**，闸门是**等级匹配 + 产能硬拦截 + 防多产倒扣**；
   案例 B 的主线是**部件码**，闸门是**齐套校验 + 首件未确认不许批量报工**。

2. **智能化不是把决策交给机器，而是把「机器算」和「人拍板」分层。**
   两个案例都严守：算法只出 2~3 个候选方案草稿、**不自动派工**；
   算法超时**自动降级为贪心**，宁可给次优解也不阻塞生产。

3. **Agent 化的第一原则：Agent 提议，规则裁决，人拍板。**
   闸门（等级、齐套、产能、首件、认证）必须由确定性代码实现，**Agent 不得绕过**。
   Agent 站在闸门上方——帮人在到达闸门之前就把事做对，而不是替人穿过闸门。

4. **交付风险不在技术，在三件"政治"事**：一把手的参与度、关键用户头两周的工时投入、
   设计冻结后的变更纪律。案例 B 把这三件事写成了**对价清单**——工期承诺的每一周都对应甲方一个动作。

5. **工期不靠排期表，靠四个动作**：双周真机演示、两个硬检查点、超阈值就范围降级、**顺延的明说**。

6. **验收不认文档，认真机**：全流程真机走通 + 扫码三秒出档案 + **三处闸门测试"拦不拦得住"** +
   全部角色逐个核对权限。**负面测试比功能清单更能证明系统真的能用。**
